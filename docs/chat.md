三种模式日常办公、代码开发、设计创意。三种模式分别对应的下面的各种Skill技能，各个Skill技能又对应不同的提示词标签，每个提示词标签对应不同的提示词。

举例如下    
1. 日常办公模式，下面有以下Skill技能：
- 文档处理、金融服务、数据分析及可视化、个人工作台、幻灯片、深度研究、视频生成、产品管理等Skill技能。
    - 文档处理对应以下提示词标签：财务分析全流程、MD转PDF文档、竞品对比分析、项目周报转Word等

        - 财务分析全流程提示词标签，对应提示词：
    帮我下载腾讯2025中期报告完整财报 PDF，从 PDF 中提取财务数据，创建一个 Excel 财务模型（包含公式和格式），然后制作一份演示文稿（使用 Ocean Gradient 配色），最后生成一份包含完整分析的 Word 报告（带目录和页眉页脚）
        - MD转PDF文档提示词标签，对应提示词：
    帮我把【上传的 Markdown 文件】转换成排版精美的 PDF 文档，要求：自定义封面页（标题 + 作者 + 日期）、自动生成目录、代码块带语法高亮、表格有交替行底色、页脚显示页码。

实现如下功能：
模式可以切换到对应的Skill技能，每个Skill技能又对应不同的提示词标签，每个提示词标签对应不同的提示词。
操作方法：
1. 选择模式：在顶部菜单中选择你需要的模式（日常办公、代码开发、设计创意）。
2. 选择Skill技能：在模式下拉菜单中选择相应的Skill技能，点击后技能名称，在输入框中插入Skill技能（输入框中显示技能名称）。输入框上方显示该Skill技能对应的提示词标签。
3. 选择提示词标签：点击提示词标签，在输入框中输入对应的提示词的内容。
