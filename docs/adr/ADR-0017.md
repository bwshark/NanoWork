# ADR-0017：管理台是独立前端

| 项 | 值 |
|---|---|

| **实现核对** | ⏳ 设计态（V2 / V3） |

## 决策

**管理台是独立前端，不并入用户工作台。**

## 背景

企业侧的管理界面（成员、权限、审批、计费）要放进用户工作台，还是单独一个前端？

## 后果

- **正面**：受众、权限模型、路由鉴权均不同；独立前端可各自演进，仅共用组件库。
- **代价**：需要维护两套前端工程与构建。
