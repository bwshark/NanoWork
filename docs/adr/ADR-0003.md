| 项 | 值 |
|---|---|

## 决策

**会话改为事件流：JSONL 追加写 + 索引层。**

事件是唯一事实源，会话视图由事件投影派生；索引是可再生的派生物，
按实体粒度读写，为回滚/分支/重放/增量同步留出能力。

## 背景

原实现把整段会话作为一个 blob（`sessions.json`）持久化：每次追加消息都要重写全量、
无法回滚/分支/重放，且 V1.5 同步时无法按实体粒度读写。

## 后果

- **正面**：回滚/分支/重放/增量同步成为可能；写放大消失。
- **代价**：需维护「实时视图 ≡ 事件投影」的不变量（→ ADR-023）；列表查询从 SQL 变为索引扫描。
- **偏差说明**：v2 原定索引层用 SQLite（`index/sessions.db`），M1 实际改为 **JSON 索引**（`src/events/indexFile.ts`）——原因是 Electron 31 = Node 20 无内置 `node:sqlite`，仓库坚持零原生依赖。取舍与代价见 ADR-022 与 v2 第 9.4 节。
