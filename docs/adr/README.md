# 架构决策记录（ADR）索引

> 编号规则：`ADR-<四位序号>`。**新增决策从 ADR-0025 起**，不再改动已发布编号；
> 若某条决策被推翻，新开一条并在本表标注被取代关系（不删除原条目）。
