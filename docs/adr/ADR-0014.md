# ADR-0014：auth 与 sync 同一 FastAPI 进程

| 项 | 值 |
|---|---|
| **状态** | 采纳（已定） |
| **实现核对** | ⏳ 设计态（V1.5） |
| **决策日期** | 2026-09-17（自 `docs/nanowork-prd-design-v2.md` 第 23 章迁入） |
| **相关章节** | v2 第 2.5.3-2 节 |
| **v2 原文表述** | auth 与 sync 同一 FastAPI 进程，不拆两个微服务 |

## 决策

**auth 与 sync 落在同一个 FastAPI 进程，不拆两个微服务。**

## 背景

认证服务与同步服务是否要拆成两个独立进程/微服务？

## 后果

- **正面**：少一个运维对象；两者的用户集合与数据集合完全重合，拆分只会引入网络跳数与一致性成本。
- **代价**：单进程即单点，扩容以横向复制整体为单位（对 V1.5 量级足够）。
