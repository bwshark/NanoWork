# ADR-0008：保持「调度在引擎、配置在前端」的自动化架构

| **v2 原文表述** | 保持「调度在引擎、配置在前端」的自动化架构 |

## 决策

**调度在引擎，配置在前端。**

前端只负责把任务配置镜像进引擎（`{workspace}/cron/jobs.json`），
实际触发与执行由引擎常驻进程负责，不依赖 UI 存活。

## 背景

定时任务可以放在客户端调度（UI 起来才跑），也可以放在引擎调度（常驻进程跑）。

## 后果

- **正面**：长时任务不依赖 UI 存活；关掉窗口任务照跑。
- **代价**：需要镜像链路与托管标记（否则用户在引擎侧手改的任务会被前端覆盖）。
- **落点**：`src/ai/cronTaskMirror.ts` / `cronMirrorWatcher.ts` / `cronRunsPoller.ts`、`toNanobotJob()`（带 `originMetadata.managedBy='smartagent'` 托管标记与 `sessionKey='api:cron-{taskId}'` 会话绑定）。
