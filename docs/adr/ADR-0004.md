# ADR-0004：权限三级防御

| 项 | 值 |
|---|---|
| **状态** | 新建 |

| **决策日期** | 2026-09-17（自 `docs/nanowork-prd-design-v2.md` 第 23 章迁入） |

| **v2 原文表述** | 权限三级防御，收口在工具网关 |

## 决策

**权限三级防御：提示词层（软）→ 工具网关（收口）→ 物理兜底（沙箱/回收站）。**

全部副作用工具调用必须经工具网关裁决；`full` 模式也不跳过物理兜底。

## 背景

权限若只写在提示词或 UI 层，被提示词注入绕过即失守。
需要一条「无论上层怎么写，副作用调用都必须过」的物理通道。

## 后果

- **正面**：企业准入前提；提示词被绕过也不会丢数据。
- **代价**：`full` 与逐条批准两轴叠加语义需明确（→ ADR-021）。
- **落点纠正**：v2 第 10.3.1 节把收口落点从「客户端 `ToolGateway`」纠正为**引擎侧**（客户端看不见也拦不住引擎进程内的工具执行）。客户端 `src/security/toolGateway.ts` 保留为 V3 多引擎参考形态，已被引擎侧取代。
