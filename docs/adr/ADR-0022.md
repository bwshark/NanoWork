## 决策

**事件流的磁盘格式归主进程独占**（IPC 只传领域对象）；
**纯索引逻辑下沉到 `src/events/indexFile.ts`** 供主进程与 Web 共用一份；
**索引层用 JSON 索引**而非 SQLite。

## 背景

事件化后有两个落点问题：磁盘格式由谁定义（渲染层拼格式会绕过契约、平台分叉），
以及索引层用什么（SQLite 强但引入原生依赖）。

## 后果

- **正面**：渲染层无法绕过契约去拼磁盘格式；纯逻辑单点实现，避免两端行为漂移（契约测试同跑内存 + Web 两个实现）。
- **代价**：V1 舍弃 SQLite（Electron 31 = Node 20 无内置 `node:sqlite`、仓库零原生依赖）以换取打包链路与跨端一致——代价是列表线性扫描、无 FTS5。
- **换回路径**：超阈值换回 SQLite 只需改 `src/events/indexFile.ts` 与 `electron/eventStore.ts`，渲染层不动。
