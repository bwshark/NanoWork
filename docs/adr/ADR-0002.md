# ADR-0002：引入 AgentRuntime 防腐层

| 项 | 值 |
|---|---|
| **状态** | 新建 |
| **实现核对** | ✅ 已落地 |
| **决策日期** | 2026-09-17（自 `docs/nanowork-prd-design-v2.md` 第 23 章迁入） |
| **相关章节** | v2 第 8.2.1 节；v2 第 8.4.1 节 |
| **v2 原文表述** | 引入 `AgentRuntime` 防腐层，收敛四处耦合 |

## 决策

**引入 `AgentRuntime` 防腐层，收敛四处耦合。**

渲染层与引擎的全部交互经 `src/ai/runtime/types.ts` 定义的 `AgentRuntime` 接口；
当前实现为 `NanobotHttpRuntime`（`src/ai/runtime/nanobotHttp/`），经 `getRuntime()` 工厂取得。

## 背景

ADR-001 把引擎挪到进程外后，渲染层各处开始直接拼引擎的 wire 字段
（`session_id` / `access_mode` / `mcpServers` / `jobs.json` ……）。实测有四处耦合点：
会话收发、配置镜像、渠道同步、任务镜像。

## 后果

- **正面**：引擎升级只改 Adapter；支持能力协商（`capabilities`），客户端可据引擎能力隐藏不可用开关。
- **代价**：契约层需持续维护「引擎特有字段不上浮」的边界纪律（→ ADR-020）。
- **落点**：`src/ai/runtime/{types.ts,index.ts}`、`src/ai/runtime/nanobotHttp/{runtime,chat,config,channels,tasks,plugins}.ts`、`codec.ts`。
