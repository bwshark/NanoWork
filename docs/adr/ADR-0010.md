# ADR-0010：跨端仍只共享 src/

| 项 | 值 |
|---|---|
| **状态** | 采纳（现状） |
| **实现核对** | 🟡 部分落地（4 处越界例外，已由 CI 棘轮固化） |
| **决策日期** | 2026-09-17（自 `docs/nanowork-prd-design-v2.md` 第 23 章迁入） |
| **相关章节** | v2 第 7 章；v2 第 18.2.3 节（三原则之 3）；v2 第 22 章（目录规划） |
| **v2 原文表述** | 跨端仍只共享 `src/`，平台差异收口 `platform` |

## 决策

**跨端只共享 `src/`，平台差异收口 `src/platform/`。**

渲染层**零 `import 'electron'`**；Electron 经 `preload` 暴露 `window.electronAPI`，
渲染层只经 `platform` 暴露的能力访问它。

## 背景

跨端有两种做法：维护两套 UI（Web / 桌面各一份），或共享一套渲染层、只在适配层分叉。

## 后果

- **正面**：一套 UI 两端复用，已验证有效。
- **代价**：平台能力新增需先在 `platform` 定义契约，不能就近直取。
- **⚠️ 实现核对（2026-09-17）**：`window.electronAPI` 有 **4 处例外**落在 `src/platform/` 之外——`src/layout/AppLayout.tsx:18`、`src/components/TitleBar.tsx:120,162,487`、`src/pages/settings/SettingsPage.tsx:44,63,80-81,88`、`src/events/electronStore.ts:27`。均有 `?.` / `isElectron()` 守卫，Web 下不崩，但绕过收口。**已固化为 CI 检查**（`.github/workflows/ci.yml` 的 `platform-boundary` 作业，基线棘轮：4 处登记为基线，新增越界即红）。
