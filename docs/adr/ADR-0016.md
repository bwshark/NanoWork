# ADR-0016：云侧单仓库起步

| 项 | 值 |
|---|---|
| **状态** | 新建 |
| **实现核对** | ⏳ 设计态（V1.5） |
| **决策日期** | 2026-09-17（自 `docs/nanowork-prd-design-v2.md` 第 23 章迁入） |
| **相关章节** | v2 第 22.2 节（目录规划） |
| **v2 原文表述** | 云侧单仓库起步，V1.5 不提前拆仓 |

## 决策

**云侧单仓库起步，V1.5 不提前拆仓。**

全部落在同一仓库用 `apps/*` 分隔，等 V3 私有化交付时再按客户环境拆分。

## 背景

云侧代码要一开始就按服务拆成多个仓库，还是先用 monorepo？

## 后果

- **正面**：只有 ① 一个进程时，拆仓净增部署与联调成本。
- **代价**：仓库会随 V2/V3 变大，需靠目录约定与 CI 保持内部边界。
