# ADR-0007：提示词外置为模板资产

| 项 | 值 |
|---|---|
| **状态** | 新建 |
| **实现核对** | ✅ 已落地 |
| **决策日期** | 2026-09-17（自 `docs/nanowork-prd-design-v2.md` 第 23 章迁入） |
| **相关章节** | v2 第 13 章（提示词工程）；v2 第 13.5 节（M3 首轮落地进度） |
| **v2 原文表述** | 提示词外置为模板资产 |

## 决策

**提示词外置为模板资产。**

模板支持变量插值，落在 `<workspace>/prompts/` 可被覆盖（引擎侧维护显式白名单）；
客户端侧有内置目录与用户级外置覆盖；装配顺序固定（提示词工程 → 身份 → 记忆）。

## 背景

提示词硬编码在源码里 → 改一句话要改代码、要发版，无法评审、无法灰度、无法做 A/B。

## 后果

- **正面**：可运营、可评审、可 A/B。
- **代价**：坏覆盖需有兜底（引擎侧白名单 + 坏覆盖 fail-open，不至于让引擎起不来）。
- **落点**：引擎 `nanobot/utils/prompt_templates.py`（`[LOCAL PATCH]`，可覆盖模板名白名单）、`nanobot/agent/context.py`；客户端 `src/lib/{promptCatalog,promptLibrary,identity,promptAssembly}.ts`、`src/pages/persona/`。
