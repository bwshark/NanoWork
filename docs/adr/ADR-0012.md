# ADR-0012：同步用 LWW + tombstone

| 项 | 值 |
|---|---|
| **状态** | 采纳（已定） |
| **实现核对** | ⏳ 设计态（V1.5） |
| **决策日期** | 2026-09-17（自 `docs/nanowork-prd-design-v2.md` 第 23 章迁入） |
| **相关章节** | v2 第 19 章；cross-platform-sync-design.md |
| **v2 原文表述** | 同步用 LWW + tombstone，不上 CRDT |

## 决策

**同步冲突消解用 LWW + tombstone，不上 CRDT。**

MVP 阶段以「复杂度可控」优先；删除用 tombstone 标记而非物理删除。

## 背景

双向同步的冲突消解可选 CRDT（无冲突、复杂度高）或 LWW（最后写入者胜、简单）。

## 后果

- **正面**：MVP 复杂度可控，实现与调试成本低。
- **代价**：并发编辑同一实体时会丢一次写入；V2 团队协作场景可能需要重新评估。
- **前置依赖**：实体必须带 `SyncMeta`（→ ADR-006，**当前未落地**）。
