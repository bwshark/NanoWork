# ADR-0011：V1 沙箱轻量（白名单 + 回收站 + 进程树强杀）

| 项 | 值 |
|---|---|
| **状态** | 采纳 |
| **实现核对** | ✅ 已落地 |
| **决策日期** | 2026-09-17（自 `docs/nanowork-prd-design-v2.md` 第 23 章迁入） |
| **相关章节** | v2 第 11.3 节（沙箱）；v2 第 2.3 节（分期） |
| **v2 原文表述** | V1 沙箱轻量（白名单 + 回收站 + 进程树强杀），V3 上容器 |

## 决策

**V1 沙箱轻量：路径白名单 + 回收站改道 + 进程树强杀；V3 企业版再上容器。**

不为「看起来安全」而过早引入容器化运维成本。

## 背景

沙箱可以直接上容器（强隔离、重运维），也可以先用进程内约束（轻、弱隔离）。

## 后果

- **正面**：避免过早容器化拖死迭代节奏。
- **代价**：V1 的隔离强度不足以承载不可信的多租户场景——所以 V1 定位是本地优先单用户客户端。
- **落点**：引擎 `nanobot/security/{workspace_access,workspace_policy,tool_approval,trash,audit}.py`、`agent/tools/{execution,shell,filesystem}.py`。
